The receipts

Check us, don't trust us.

  1. Servers None. There is no GRØD server — nothing the app captures has anywhere of ours to go. Not for sync, not for analytics, not for anything. You can't leak to infrastructure that doesn't exist.
  2. Network Exactly one file in the app can open a connection — used only to download optional transcription models you ask for. Enforced by a source-scan test that fails the build if a second one appears.
  3. Downloads Every downloaded file is SHA-256-verified against a pinned release before it's trusted. HTTPS to two allowed domains; dependencies are forced offline too.
  4. Deletion "Recording removed" is only ever said after it's proven true. Optional 90-day auto-purge removes audio only — transcripts and notes always survive.
  5. Telemetry None. No analytics, no phone-home, no account to attach them to. Even local diagnostics use a closed vocabulary that cannot contain your content.

We can't show you the source, so we show you behavior: switch Wi-Fi off and GRØD keeps working; watch the network and nothing leaves.
